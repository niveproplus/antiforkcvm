# Anti-Forkie CollabVM
A anti-forkie for collaborative virtual machine websites like CollabVM and Fixtux // VM. My GitHub username is the same as the one I use for CollabVM and Fixtux // VM.

# What are forkies?
Forkies are users that make the virtual machines unusable in any way. 
Usually, being a forkie is not allowed, and this script is to combat un-banned forkies.
