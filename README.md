# Anti-Forkie CollabVM
A anti-forkie for collaborative virtual machine websites like CollabVM and Fixtux // VM. My GitHub username is the same as the one I use for CollabVM and Fixtux // VM.

# What are forkies?
Forkies are users that make the virtual machines unusable in any way. 
Usually, being a forkie is not allowed, and this script is to combat un-banned forkies.

# What are BSODers?
BSODers are users that cause a BSOD (Blue Screen of Death) on the virtual machine. BSODers are annoying but usually allowed, and this script also combats BSODers.

# What does this script do?
theantifork.bat.cmd.bat is the main script, with a funny triple file extension. It disables tools BSODers and forkies use. 
users.bat just creates users, preventing forkies from password-locking accounts by making so many accounts.

# What are forkie files?
The directory "Forkie Files" contains evidence of forkies and BSODers destroying or BSODing collaberative virtual machines
